Why Internet Communicator?

Modern browsers have become bloated with background telemetry, heavy installers, and cluttered menus. Internet Communicator brings back the optimism of mid-2000s software—using 100% pure native scripts (.vbs, .applescript, and .sh) to launch real websites cleanly with zero bloat.

Release Roadmap (1.0 → 3.0)

  • Version 1.0: Initial Frutiger Aero Windows release with Speed Dial, Private Mode, Bookmarks, and History.
  • Version 1.1: Cross-platform macOS support, custom homepage (/sethome), and search engine switcher (/engine).
  • Version 1.2 (Current): Linux support (.sh), maximized windows, multi-tab launcher (/tabs), direct YouTube/Wiki search, and history backup/purge.
  • Versions 1.3 – 1.5: GitHub search (/gh), clipboard launcher (/paste), release notes (/news), custom Speed Dial editor, and user profiles.
  • Version 2.0 (Flat Design Era): Major visual overhaul shifting to crisp Flat Design with an auto-generated clickable HTML Start Page dashboard inside pure VBScript.
  • Version 3.0 (Modern Glass Era): Translucent glass UI overhaul, workspace presets, and portable mode.
