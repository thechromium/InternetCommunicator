Welcome to Internet Communicator 1.1—a sleek, ultra-fast web launcher built for both Windows and macOS. Set your custom homepage with /sethome, switch search engines with /engine, and browse cleanly with Private Incognito Mode.

Custom Homepage & Search

Set your own Speed Dial #1 homepage anytime with /sethome and switch between Google, Bing, or DuckDuckGo using /engine.

Private Incognito Mode

Toggle /private anytime to launch InPrivate / Incognito windows without saving a single entry to your history log.

Version 1.1 brings native support for both Windows (.vbs) and macOS (.applescript) with zero heavy installers.

Custom Bookmarks

Save your favorite websites permanently with /add and pull up your personal speed-dial list anytime using /favs.
