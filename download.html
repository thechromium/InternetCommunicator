Choose your operating system below. No installation wizard or admin rights required:

Download for Windows (.vbs) Download for macOS (.applescript) Download for Linux (.sh)

Windows Setup

Download InternetCommunicator.vbs, place it in its own folder, and double-click to launch maximized windows.

macOS Setup

Download InternetCommunicator.applescript, open in Apple's built-in Script Editor, and press Run.

Linux Setup

Download InternetCommunicator.sh, open Terminal in your folder, and run chmod +x InternetCommunicator.sh && ./InternetCommunicator.sh.

What's New in 1.2

  • Linux Support: Added native bash/zenity edition (InternetCommunicator.sh)—suggested by Diego!
  • Maximized App Windows: Websites now open full-screen right away with automatic browser fallback.
  • New Slash Commands: Added /tabs, /reopen, /yt, /wiki, /downloads, /about, and a cleaner categorized /help menu.
  • History Backup & Purge: /clear automatically saves a backup copy to your Downloads folder, while /purge permanently erases all logs.
