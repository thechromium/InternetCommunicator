Windows Setup

Download InternetCommunicator.vbs, place it in its own folder, and double-click to launch maximized windows.

macOS Setup

Download InternetCommunicator.applescript, open in Apple's built-in Script Editor, and press Run.

Linux Setup

Download InternetCommunicator.sh, open Terminal in your folder, and run chmod +x InternetCommunicator.sh && ./InternetCommunicator.sh.

What's New in 1.3

  • Smart Built-In Features: Live Favs & Visits counter, customizable Speed Dial slots (1–5), smart domain typo auto-correct, and a Focus Site Blocker (ic_blocked.txt).
  • Clipboard & Quick Tools: Open copied links with /paste, save notes with /note & /notes, run timers (/timer), or launch Calculator & Notepad.
  • Direct Site & Search Commands: Added /twitter (or /x), /gh, /reddit, /maps, /dict, /amazon, /ebay, /translate, /weather, /newsweb, /speedtest, and built-in /news release notes.
